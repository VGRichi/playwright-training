# ⌨️ VS Code Shortcuts (Windows)

## 🚀 Most Used
| Action | Shortcut |
|:---|:---|
| Command Palette | `Ctrl+Shift+P` |
| Quick open file | `Ctrl+P` |
| Toggle terminal | `` Ctrl+` `` |
| New terminal | `` Ctrl+Shift+` `` |
| Toggle sidebar | `Ctrl+B` |
| Settings | `Ctrl+,` |
| Save / Save all | `Ctrl+S` / `Ctrl+K S` |
| Close tab | `Ctrl+W` |
| Reopen closed tab | `Ctrl+Shift+T` |

## ✏️ Editing
| Action | Shortcut |
|:---|:---|
| Copy line (no selection) | `Ctrl+C` |
| Cut line | `Ctrl+X` |
| Delete line | `Ctrl+Shift+K` |
| Move line up / down | `Alt+↑` / `Alt+↓` |
| Duplicate line up / down | `Shift+Alt+↑` / `Shift+Alt+↓` |
| Insert line below / above | `Ctrl+Enter` / `Ctrl+Shift+Enter` |
| Toggle line comment | `Ctrl+/` |
| Toggle block comment | `Shift+Alt+A` |
| Indent / Outdent | `Ctrl+]` / `Ctrl+[` |
| Format document | `Shift+Alt+F` |
| Undo / Redo | `Ctrl+Z` / `Ctrl+Y` |

## 🖱️ Multi-Cursor & Selection
| Action | Shortcut |
|:---|:---|
| Select next match | `Ctrl+D` |
| Select all matches | `Ctrl+Shift+L` |
| Add cursor anywhere | `Alt+Click` |
| Add cursor above / below | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| Column (box) select | `Shift+Alt+Drag` |
| Expand / shrink selection | `Shift+Alt+→` / `Shift+Alt+←` |
| Select current line | `Ctrl+L` |

| Peek definition | `Alt+F12` |
